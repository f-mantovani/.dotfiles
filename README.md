### Installation with WSL / Termux


## WSL - Ubuntu
```bash
sudo install apt clang zsh brew build-essentials git
```

## Termux
```bash
pkg install apt clang zsh brew build-essentials git
```

## Change to zsh
```bash
chsh "$(which zsh)"
```

## Clone the .dotfiles
```zsh
git clone https://github.com/f-mantovani/.dotfiles.git
```
